# 환경설정 명세

ReportQA가 실행될 때 읽는 설정 값(환경 변수)의 목록과 의미를 정리한 문서입니다.

---

## 1. 기본 개념

### 환경 변수란?
프로그램 코드 **밖에** 따로 적어두는 설정 값입니다. API 키나 비밀번호를 코드 안에 직접 쓰면 GitHub에 올릴 때 함께 공개되기 때문에, 이런 값은 코드와 분리해서 관리합니다.

### 파일 두 개의 역할

| 파일 | 내용 | GitHub에 올리나? |
|---|---|---|
| `.env` | **실제 값** (진짜 API 키, 비밀번호) | **절대 안 올림** (`.gitignore`에 등록됨) |
| `.env.example` | 항목 이름과 설명만 있고 값은 비워둔 **견본** | 올림 |

처음 프로젝트를 받은 사람은 `.env.example`을 복사해 `.env`를 만들고, 자기 값을 채워 넣습니다.

```bash
cp .env.example .env
```

### 작성 규칙
- 이름은 **대문자와 밑줄**만 씁니다. (예: `OPENAI_API_KEY`)
- 한 줄에 하나씩 `이름=값` 형식으로 씁니다. `=` 양옆에 **띄어쓰기를 넣지 않습니다.**
- 비밀 값(🔒 표시)은 `.env`에만 넣습니다. `.env.example`, 코드, 문서, 채팅 어디에도 실제 값을 적지 않습니다.
- 새 설정이 필요해지면 **이 문서 → `.env.example` → `.env`** 순서로 함께 고칩니다.

## 2. 설정 항목

**필요 시점**은 개발 일정상 그 설정이 처음 쓰이는 주차입니다. 아직 필요 없는 항목은 그 주차가 되면 `.env.example`에 추가합니다.

### 2-1. OpenAI (1주차)

| 이름 | 🔒 | 필수 | 설명 | 예시 값 |
|---|---|---|---|---|
| `OPENAI_API_KEY` | 🔒 | 필수 | OpenAI API 키. 사용량만큼 비용이 청구됨 | `sk-...` (실제 값은 `.env`에만) |
| `LLM_MODEL` | | 필수 | 답변 생성에 쓰는 모델 | 1주차에 최신 모델·가격 확인 후 기입 |
| `VISION_MODEL` | | 필수 | 차트·표 이미지를 글(캡션)로 바꾸는 모델. 이미지 입력을 지원해야 함 | 1주차에 확인 후 기입 |
| `EMBEDDING_MODEL` | | 필수 | 글을 벡터(숫자 목록)로 바꾸는 모델 | 1주차에 확인 후 기입 |

> 모델 이름을 코드에 직접 쓰지 않고 설정으로 빼두면, 평가할 때 모델만 바꿔가며 비교하기 쉽습니다.

### 2-2. 경로 (2주차)

| 이름 | 🔒 | 필수 | 설명 | 예시 값 |
|---|---|---|---|---|
| `DATA_DIR` | | 선택 | 데이터 폴더 위치 | `./data` (기본값) |

### 2-3. 문서 처리 (2~4주차)

| 이름 | 🔒 | 필수 | 설명 | 초기값 |
|---|---|---|---|---|
| `CHUNK_SIZE` | | 선택 | 청크 하나의 최대 글자 수 | `800` |
| `CHUNK_OVERLAP` | | 선택 | 앞뒤 청크가 겹치는 글자 수. 문장이 잘려 문맥이 끊기는 것을 줄임 | `100` |

> 초기값은 출발점일 뿐이며, 평가 결과를 보고 조정합니다. 바꿀 때마다 `devlog.md`에 이유와 결과를 기록합니다.

### 2-4. 검색 (6주차)

| 이름 | 🔒 | 필수 | 설명 | 초기값 |
|---|---|---|---|---|
| `RETRIEVE_TOP_K` | | 선택 | 1차 검색에서 가져올 후보 수 | `20` |
| `RERANK_TOP_K` | | 선택 | 리랭킹 후 최종으로 쓸 근거 수 | `5` |
| `RERANKER_MODEL` | | 선택 | 리랭커 모델 이름 | 6주차에 확인 후 기입 |
| `RELEVANCE_THRESHOLD` | | 선택 | 이 점수보다 낮으면 "모름"으로 답함 | "모름" 문항 평가로 결정 |

### 2-5. 데이터베이스 (5주차)

| 이름 | 🔒 | 필수 | 설명 | 예시 값 |
|---|---|---|---|---|
| `POSTGRES_USER` | | 필수 | DB 사용자 이름 | `reportqa` |
| `POSTGRES_PASSWORD` | 🔒 | 필수 | DB 비밀번호 | 직접 정한 값 (`.env`에만) |
| `POSTGRES_DB` | | 필수 | DB 이름 | `reportqa` |
| `POSTGRES_HOST` | | 필수 | DB 주소 | 로컬: `localhost` / Docker: `db` |
| `POSTGRES_PORT` | | 선택 | DB 포트 번호 | `5432` (기본값) |

> `POSTGRES_HOST`는 실행 방법에 따라 달라집니다. 내 PC에서 바로 실행하면 `localhost`, Docker Compose 안에서 실행하면 컨테이너 이름인 `db`를 씁니다. (구조도 5 참고)

### 2-6. 화면 (7주차)

| 이름 | 🔒 | 필수 | 설명 | 예시 값 |
|---|---|---|---|---|
| `API_BASE_URL` | | 필수 | Streamlit 화면이 요청을 보낼 FastAPI 서버 주소 | 로컬: `http://localhost:8000` / Docker: `http://api:8000` |

### 2-7. 기타

| 이름 | 🔒 | 필수 | 설명 | 예시 값 |
|---|---|---|---|---|
| `LOG_LEVEL` | | 선택 | 로그를 얼마나 자세히 남길지 | `INFO` (개발 중 자세히 보려면 `DEBUG`) |

## 3. 보안 수칙

1. **`.env`는 커밋하지 않습니다.** 커밋 전에 `git status`로 `.env`가 목록에 없는지 확인합니다.
2. **키를 채팅, 캡처 화면, 노트북 출력에 노출하지 않습니다.** 노트북에서 `print(api_key)` 같은 코드는 쓰지 않습니다.
3. **OpenAI 대시보드에서 월 사용 한도를 설정**해 둡니다.
4. **키가 노출됐다면** 바로 OpenAI 대시보드에서 해당 키를 삭제(폐기)하고 새로 발급합니다. GitHub에 한 번이라도 올라갔다면, 나중에 파일을 지워도 기록에 남기 때문에 반드시 폐기해야 합니다.

## 4. 코드에서 읽는 방법 (예정)

- **1~4주차 (노트북):** `python-dotenv` 라이브러리로 `.env`를 읽습니다.
- **5주차 이후 (서버):** `app/config.py` 한 곳에서 모든 설정을 읽고, 다른 코드는 `config.py`에서 값을 가져다 씁니다. 설정이 한 곳에 모여 있으면 무엇이 쓰이는지 찾기 쉽고, 빠진 필수 값이 있으면 실행할 때 바로 알려줄 수 있습니다.

> 구체적인 코드는 해당 주차에 확인을 받은 뒤 작성합니다.
