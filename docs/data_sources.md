# 데이터 출처 목록

ReportQA에서 사용하는 보고서 PDF의 출처, 이용 조건, 특징을 기록하는 문서입니다.

> 원본 PDF는 용량과 저작권 문제로 **GitHub에 올리지 않습니다** (`.gitignore`의 `data/*` 규칙).
> 대신 이 문서에 다운로드 링크와 이용 조건을 남겨, 누구나 같은 데이터를 직접 받아 재현할 수 있게 합니다.

---

## 1. 선정 기준

보고서를 고를 때 아래 조건을 **모두** 확인합니다.

| 번호 | 기준 | 이유 |
|---|---|---|
| 1 | 국내 공공기관이 발행한 통계·동향 보고서 | 출처가 분명하고 이용 조건이 공개되어 있음 |
| 2 | 차트와 표가 많음 (각 5개 이상 권장) | 이 프로젝트의 핵심이 "차트·표 질문"이기 때문 |
| 3 | 스캔본이 아닌 텍스트 PDF | 스캔본은 글자를 추출할 수 없음 (아래 확인 방법 참고) |
| 4 | 이용 조건 확인 가능 (공공누리 등) | 사용 가능 여부를 근거로 남기기 위해 |
| 5 | 분량 20~80쪽 | 너무 짧으면 질문을 만들기 어렵고, 너무 길면 처리 비용이 커짐 |
| 6 | 3개 문서의 차트 종류가 서로 다르면 좋음 | 막대·꺾은선·원형 등 다양한 차트에서 성능을 확인하기 위해 |

### 스캔본 확인 방법
1. PDF를 열고 본문 글자를 마우스로 드래그합니다.
2. 글자가 파랗게 **선택되면** 텍스트 PDF입니다. 사용할 수 있습니다.
3. 글자 대신 **사각형 영역 전체**가 선택되면 이미지(스캔본)입니다. 제외합니다.

### 이용 조건 확인 방법 (공공누리)
공공기관 자료에는 보통 "공공누리" 마크가 붙어 있습니다. 보고서 표지 뒷면, 마지막 쪽, 또는 다운로드 페이지에서 확인합니다.

| 유형 | 조건 | 이 프로젝트에서 |
|---|---|---|
| 제1유형 | 출처 표시 | **가장 권장** |
| 제2유형 | 출처 표시 + 상업적 이용 금지 | 사용 가능 (비상업 개인 프로젝트), 유형 기록 |
| 제3유형 | 출처 표시 + 변경 금지 | 유형을 기록하고, 원본을 수정·재배포하지 않음 |
| 제4유형 | 출처 표시 + 상업적 이용 금지 + 변경 금지 | 유형을 기록하고, 원본을 수정·재배포하지 않음 |
| 표시 없음 | 이용 조건 불명확 | **사용하지 않음** |

> 가능하면 제1유형 문서를 우선 고릅니다. 어떤 유형이든 원본 PDF는 재배포하지 않고, 화면과 README에는 출처를 표시합니다.

## 2. 저장 규칙

- **저장 위치:** `data/pdf/`
- **파일 이름:** 영문 소문자, 숫자, 밑줄(`_`)만 사용합니다.
  - 형식: `발행연도_주제.pdf` (예: `2025_employment_trend.pdf`)
  - 한글 파일 이름은 WSL·Docker·서버 사이를 오갈 때 글자가 깨지는 경우가 있어 피합니다.
- **문서 ID:** `D01`, `D02`, `D03`처럼 순서대로 붙입니다. 평가 테스트셋에서 "정답이 있는 문서"를 가리킬 때 이 ID를 씁니다.
