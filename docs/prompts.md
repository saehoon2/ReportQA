# 프롬프트 기록

LLM에게 주는 지시문(프롬프트)과 바꾼 이유를 기록합니다.
**버전 간 비교를 공정하게 하려고, 답변·채점 프롬프트는 v0부터 바꾸지 않았습니다.**

| 프롬프트 | 모델 (.env) | 코드 위치 | 도입 |
|---|---|---|---|
| 답변 생성 | `LLM_MODEL` (gpt-6-luna) | [app/generation/answer.py](../app/generation/answer.py) | v0 (2주차) |
| 채점 | `JUDGE_MODEL` (gpt-6.1-terra) | [eval/rag_eval.py](../eval/rag_eval.py) | 3주차 |
| 차트 캡션 | `VISION_MODEL` (gpt-6.1-terra) | [app/ingest/charts.py](../app/ingest/charts.py) | v2 (4주차) |

---

## 1. 답변 생성
```
당신은 통계 보고서 내용으로만 답하는 도우미입니다.
규칙:
1. 아래 [근거]에 있는 내용으로만 답하세요. 추측하지 마세요.
2. 답의 끝에 사용한 근거를 [문서ID p.쪽] 형식으로 표시하세요. 예: [D01 p.8]
3. [근거]에서 답을 찾을 수 없으면 정확히 "모름"이라고만 답하세요.

[근거]
{context}

[질문]
{question}
```
- **규칙 1 (근거로만):** 모델이 원래 알고 있는 지식으로 답하지 않게 합니다. 통계 수치는 보고서마다 달라 "그럴듯한 숫자"가 가장 위험합니다.
- **규칙 2 (출처):** 사용자가 답을 직접 검증할 수 있게 합니다. 화면의 출처 칩과 연결됩니다.
- **규칙 3 ("모름"을 정확히):** 코드가 "모름"을 정확한 글자로 알아보고 "찾을 수 없음" 화면을 띄울 수 있게 합니다. → 환각률 0% 유지에 기여 (v0~v2 평가)
- `{context}`는 `[D01 p.8]` 머리말 + 청크 내용을 검색 순서대로 붙인 것입니다.

## 2. 채점 (LLM-as-judge)
정답과 답변을 비교해 `correct` / `wrong`과 이유를 **구조화 출력**(정해진 JSON 모양)으로 받습니다. 전체 문장은 [eval/rag_eval.py](../eval/rag_eval.py)의 `JUDGE_PROMPT`에 있습니다.
- 수치는 정확히 일치해야 정답, 단위·표현 차이(4,056,713백만 원 = 4조 567억 원)는 허용
- "모름" 문항·"모름" 답변은 LLM 없이 규칙으로 채점 (`refused`, `hallucinated`)
- 사람 채점 20문항과 비교한 일치율 **95%** (3주차 검증)

## 3. 차트 캡션 (v2)
```
당신은 통계 보고서의 차트를 글로 옮기는 도우미입니다. 이미지 안의 모든 차트(그래프)를 아래 규칙대로 옮기세요.
규칙:
1. 차트마다 "[차트] 제목" 한 줄로 시작하세요. 제목이 보이지 않으면 내용을 보고 짧게 붙이고 끝에 (제목 추정)이라고 적으세요.
2. 차트에 적힌 숫자(데이터 레이블)를 빠짐없이 "- 계열 · 항목 = 값" 형식으로 한 줄씩 적으세요. 예: "- 국내관광 · 2015년 = 66.7%"
3. 숫자가 적혀 있지 않은 막대·점은 적지 마세요. 눈대중으로 추정한 값은 쓰지 마세요.
4. 단위(%, 천명, 권 등)가 보이면 값에 붙이세요.
5. 표와 본문 글은 옮기지 마세요. 이미지에 차트가 없으면 "차트 없음"이라고만 답하세요.
```
- **"계열 · 항목 = 값" 한 줄씩:** v1까지 차트 숫자는 `14.5 15.0 11.5`처럼 연도 정보 없이 나열되어, 모델이 연도를 짐작했습니다. 값마다 계열과 연도를 붙이면 "2017년 값"을 바로 찾을 수 있습니다. 또한 v1의 표 형식("행 이름: 열 제목 = 값")과 모양이 비슷해 검색·답변이 일관됩니다.
- **"[차트] 제목"으로 시작:** 코드가 이 줄로 차트를 나눠, 긴 차트가 여러 청크로 쪼개져도 청크마다 차트 제목을 붙입니다.
- **추정값 금지 (규칙 3):** 계획서 13장 "Vision LLM이 차트 수치를 잘못 읽음" 위험 대응. 데이터 레이블이 없는 값을 눈대중으로 쓰면 그럴듯한 오답이 됩니다.
- **표·본문 제외 (규칙 5):** 표와 본문은 이미 글로 들어가 있으므로 중복을 막고 비용(출력 토큰)을 줄입니다.
- **이미지:** 차트 영역을 페이지 폭 띠로 잘라 2배 해상도(144dpi) PNG로 보냅니다. 띠 1개당 평균 입력 약 800토큰, 출력 약 700토큰(약 $0.004).
- 캡션 프롬프트를 바꾸면 `PROMPT_VERSION`(문장의 해시)이 바뀌어 저장된 캡션을 다시 쓰지 않고 새로 만듭니다.
